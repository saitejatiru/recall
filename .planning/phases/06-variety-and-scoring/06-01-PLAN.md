# Phase 6 — Question Variety & 1-100 Scoring

## Problem

1. **Repeated questions on consecutive days (days 1-30):**
   - `dayCase()` and `dayInterview()` use `selectByWeakSpot()`, which returns `items[0]` whenever the weak-spot tag set is empty or unchanged — so Day 1 and Day 2 get the **same** case and interview question.
   - `dayQuestion()` (speak step) uses `QUESTIONS[(day()-1) % 9]` — with only 9 questions, day 10 = day 1, day 19 = day 10, etc. (But Day 1 ≠ Day 2, so the user's Day 2 repeat was the case & interview, not the speak question.)
   - **Vocab was different** because VOCAB has 30 unique arrays, one per day.

2. **Report score scale:** User wants 1-100 instead of 1-10 in the performance report.

## Approach (ponytail: lazy minimum)

### Fix 1: No-repeat selection

Add one pure function to `logic.js`:

```js
function selectByWeakSpotNoRepeat(items, topTags, lastIdx) {
  var topTagsSet = new Set(topTags);
  var best = -1;
  for (var i = 0; i < items.length; i++) {
    if (i === lastIdx) continue;
    var tags = items[i].targetsTags || [];
    if (tags.some(function(t) { return topTagsSet.has(t); })) return items[i];
    if (best < 0) best = i;
  }
  return items[best >= 0 ? best : 0];
}
```

This skips yesterday's item index. If no weak-spot match exists (excluding yesterday's), it picks the first non-yesterday item. Fallback to `items[0]` only when there's a single item.

Then update `app.js`:
- `dayCase()`: read yesterday's `caseIdx` from storage and pass it as `lastIdx`.
- `dayInterview()`: same with `interviewIdx`.
- `dayQuestion()`: Change from modular cycling to weak-spot-aware selection with no-repeat, storing a `questionIdx` like case/interview already do.

### Fix 2: Report 1-100

The AI still scores 1-10 (don't change the Worker prompt). Multiply × 10 for display only.

- In `logic.js` → `computeDayReport`: change `averageScore` to be `Math.round(avg * 10)` (range 10-100).
- In `app.js` → all `/10` displays → `/100`.
- In step feedback chips: `af.score * 10` + `/100`.
- Copy-report text: `/100`.

### 2c. No-repeat speak question

**Find:**
```js

```

**Replace with:**
```js
function dayQuestion() {
  var p = dayPack(); if (p) return p.question;
  var vd = data[activeDateKey()];
  if (!vd || vd.questionIdx === undefined) {
    var lastQIdx = -1;
    for (var k in data) {
      if (k.indexOf('d-') === 0 && data[k] && data[k].dayNumber === day() - 1 && data[k].questionIdx !== undefined) {
        lastQIdx = data[k].questionIdx; break;
      }
    }
    var i = QUESTIONS.indexOf(LOGIC.selectByWeakSpotNoRepeat(QUESTIONS, LOGIC.computeTopWeakSpots(data, todayStr), lastQIdx));
    if (i < 0) i = (day() - 1) % QUESTIONS.length;
    if (!vd) return QUESTIONS[i];
    vd.questionIdx = i; save();
  }
  return QUESTIONS[vd.questionIdx];
}
```

Note: `QUESTIONS` don't have `targetsTags`, so `selectByWeakSpotNoRepeat` will always fall to the "first non-last" path, which gives rotation. This is fine — speak questions don't target weak spots.
