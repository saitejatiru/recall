# Phase 5 — Daily Performance Report & Feedback Loop

## Overview
Transform the Day Summary screen into an actionable Daily Performance Report that shows:
1. **Overview & Scorecard:** Overall score, filler count, vocab learned, and mistake rectification rate.
2. **What Landed (Strengths):** Positive feedback on clear structure, metrics, or good instincts.
3. **Mistakes & Fixes (Areas to Improve):** For each step, exactly what went wrong and the tailored rewritten better line.
4. **Rectified Mistakes:** If the learner used "Try again with the fix", track and display whether the mistake was rectified.
5. **Vocab & Teach-Back Performance:** Sentences written, AI correctness verdicts, and teach-back concept explanations with gap analysis.

## Tasks

### Task 1: Data Persistence in app.js (RPT-01, RPT-02, RPT-05)
- Store `res.landed` and `res.betterLine` in `vd[stepId].aiFeedback`.
- Persist AI vocab verdicts and corrected sentences in `vd.vocab.aiResults`.
- Persist teachback results in `vd.recall.teachback`.
- Persist retry results (`text`, `improved`, `fix`, `betterLine`) in `sd.retry`.
- Scrub personal email and LinkedIn URLs from `SAITEJA_RESUME` in `app.js`.

### Task 2: Pure Aggregation in logic.js (RPT-03)
- Implement `LOGIC.computeDayReport(dayData)` to summarize:
  - `averageScore`, `scoreCount`, `totalFillers`, `rectifiedCount`, `attemptCount`
  - `strengths`: list of landed items
  - `stepAnalyses`: array of step breakdowns (question, answer, score, landed, fix, betterLine, tags, retry)
  - `vocabSummary`: list of vocab sentences, verdicts, and corrections
  - `teachbackSummary`: teachback concept, answer, gaps, and model explanation
- Add unit tests in `logic.test.mjs` verifying `computeDayReport`.

### Task 3: Visual Report UI in app.js (RPT-03, RPT-04)
- Create `renderDailyReport(dayData, dayNum)` with:
  - Clean cards, score badge, metrics row.
  - "What You Did Well" section.
  - "Mistakes & How to Improve" section with before/after comparisons.
  - "Rectified Improvements" badges when retries improve.
  - Print / Export button for reviewing or saving.
- Mount inside `renderSummary(dayData)`.
