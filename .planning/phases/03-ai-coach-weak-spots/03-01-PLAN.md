## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Browser → Worker | Passcode + origin guard (existing); coach payload body is untrusted |
| Worker → NIM/Gemini | Key in Worker secret; model name validated by isSafeModel |
| Model reply → Worker | Treated as untrusted text; parseJSONReply + validateCoachReply before forwarding |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-03-01 | Tampering | coach case — user answer/resume in prompt | high | mitigate | All user content in named XML blocks; system prompt instructs model to treat as data only; injection guard tested |
| T-03-02 | Information Disclosure | resumeExcerpt in Worker log | medium | mitigate | resumeExcerpt capped at 1500 chars; Worker console.log logs only model/key/status/tokens, never message bodies |
| T-03-03 | Denial of Service | large answer payload exhausting max_tokens budget | low | mitigate | answer capped at 4000 chars (same slice as bakeoff answers); max_tokens=400 for answer, 100 for teachback |
| T-03-04 | Spoofing | auth bypass on coach task | low | accept | Existing origin+passcode guard applies to all tasks including coach; no additional auth surface added |
| T-03-05 | Tampering | invalid tags in model reply stored to data | medium | mitigate | validateCoachReply rejects any tag outside VALID_TAGS Set; returns {error:"malformed_response"} |
| T-03-SC | Tampering | npm/pip/cargo installs | high | mitigate | No new packages; Worker has no npm dependency; slopcheck not needed |
</threat_model>
