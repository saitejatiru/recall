<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| AI model reply → innerHTML | Model text is untrusted; esc() mandatory on every field |
| Browser localStorage → todayTerms / learnedWordIds | User-controlled data used in payload construction |

## STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-03-09 | Tampering (XSS) | model reply fields in innerHTML | high | mitigate | esc() applied to every model-originated string (fix, betterLine, landed, modelAnswer, correctedSentence, socratiQ, betterExplanation) before innerHTML insertion — enforced by code review in acceptance |
| T-03-10 | Information Disclosure | resumeExcerpt in network payload | medium | mitigate | Capped at 1500 chars; sent only to the user's own Cloudflare Worker; not logged server-side |
| T-03-11 | Denial of Service | model answer / try-again button clicked repeatedly | low | mitigate | Show model answer button is disabled during the in-flight call; try-again button removed after first click; retry fires only once per step |
| T-03-12 | Repudiation | weak-spot tags stored without validation | medium | mitigate | Worker validateCoachReply already enforces VALID_TAGS; malformed replies return error and are not stored |
| T-03-SC | Tampering | npm/pip/cargo installs | high | mitigate | No new packages; app.js is vanilla JS; zero new CDN imports |
</threat_model>
